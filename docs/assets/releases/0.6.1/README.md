# HalalDL v0.6.1 release artwork

`hero-light.png` and `hero-dark.png` are deterministic release cards generated by `generate-images.py`.

Run from the repository root:

```powershell
python docs/assets/releases/0.6.1/generate-images.py
```

The generator uses the shipped HalalDL brand mark and Windows Segoe UI fonts. It does not access network or user data.
