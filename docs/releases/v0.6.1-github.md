# HalalDL v0.6.1 — Privacy and Security Maintenance

This maintenance release removes the app's legacy telemetry path, makes website-to-app links queue-only by default, and tightens the desktop security boundary. Your downloads, history, presets, settings, and local media remain intact.

![Privacy and Security Maintenance](https://raw.githubusercontent.com/Asdmir786/HalalDL/main/docs/assets/releases/0.6.1/hero-light.png)

## Privacy maintenance

- Desktop telemetry collection and transmission have been removed.
- Startup cleanup deletes only the legacy `telemetry.json` identifier file.
- Downloads, history, presets, settings, cookies, completed files, and other local media are not removed.

## Safer website-to-app links

- `halaldl://download?url=...` queues a valid HTTP or HTTPS link without starting it automatically.
- Automatic starting requires the explicit `start=1` parameter.
- Invalid schemes, embedded credentials, malformed input, and oversized URLs are rejected.

## Desktop hardening

- Tightened the Tauri content security policy and capability permissions.
- Restricted file-opening behavior to approved local paths and supported targets.
- Existing local-first download, queue, history, preset, and library workflows are preserved.

## Choose a download

- **Full** is recommended for most Windows users and includes the broadest bundled tool support.
- **Lite** is smaller and expects more supporting tools to be managed separately.
- **Portable** is a self-contained ZIP with manual folder replacement for updates.
- Installers are unsigned, so Windows SmartScreen may appear. Verify downloads against `SHA256SUMS.txt` when you need checksum assurance.
